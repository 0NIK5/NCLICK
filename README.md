# NCLICK — Счётчик Эспандера

Веб-приложение для автоматического подсчёта повторений при тренировке с кистевым эспандером. Работает в браузере без установки — только микрофон.

## Как это работает

Программа слушает микрофон и детектирует характерный щелчок эспандера (пластик об пластик). При достижении заданного числа повторений — звуковой сигнал и автосброс счётчика, чтобы сразу переходить к другой руке.

## Метод детекции

Используется **onset detection** — обнаружение по резкому скачку энергии в заданной полосе частот (Band-Pass).

В отличие от анализа абсолютной громкости:
- Фоновый шум, музыка, гул — стабильная энергия, скачка нет → не срабатывает
- Щелчок эспандера — короткий импульс, резкий рост энергии в полосе → срабатывает

Цепочка обработки: `Микрофон → AnalyserNode (FFT 4096) → Энергия в полосе → Delta → Детекция`

`ScriptProcessor` и ZCR (zero crossing rate) не используются.

## Настройка

**1. Нижняя граница (Low-Cut)** — отсекает всё ниже заданной частоты (гул, голоса, басы).

**2. Верхняя граница (High-Cut)** — отсекает всё выше (высокочастотные помехи).

Активная полоса подсвечивается зелёным на спектре. Цель — поместить щелчок эспандера в это окно.

**3. Порог чувствительности** — насколько резким должен быть скачок энергии для срабатывания. Увеличивай, если слишком много ложных срабатываний.

**Cooldown** между срабатываниями: 333 мс.

## Запуск

Открыть `index.html` в браузере (Chrome на ПК, Safari на iOS) → нажать "Включить микрофон" → разрешить доступ.

## Совместимость

- Chrome (Desktop)
- Safari (iOS / macOS)
- Firefox, Edge
